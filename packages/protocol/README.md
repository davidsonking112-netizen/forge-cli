Forge protocol v1 is a line-oriented JSON event stream. One complete JSON object is written per line. The Node.js supervisor and Python worker use the same envelope fields: `protocol`, `id`, `sessionId`, `type`, and `timestamp`.

Standard output is reserved for protocol messages. Standard error is reserved for diagnostics and must never be parsed as an event. Every tool proposal has a named tool, risk classification, JSON arguments, and reason. Every tool result reports approval, success, duration, and either bounded output or a structured error.

The v0.9.7 contract retains first-class `agent.delegation` events for bounded specialist activity and optional session autonomy profiles. It adds bounded `agent.scratchpad` events containing short task, inspection, current-step, change, verification, and next-action entries, plus `agent.checklist` events containing item IDs, labels, user-facing expectations, bounded status, and optional notes. Checklist and scratchpad state are planning metadata only and never authorize a tool. Delegation events may include bounded non-secret budget telemetry for profile, planned/used roles and turns, context/output character counts, and skipped-role reasons.
`session.start` may include a bounded workspace fingerprint and a recovery assessment identifying `continue`, `re-plan`, or `manual-intervention` without authorizing replay. Unified-diff application is represented by the reversible-write `workspace.apply_unified_diff` tool and remains supervisor approval-gated; read-only previews describe a selected file-level change set and deterministic digest, while application reuses preflight, remains stale-validated, checkpointed, and all-or-rollback. Approval-session decisions carry an ephemeral exact-argument scope and expiry, with bounded path metadata, rather than blanket authorization.

The canonical event schema is [`schema.json`](./schema.json). The TypeScript implementation is in [`src/index.ts`](./src/index.ts). MCP and ACP adapters map their wire-level events to these internal boundaries rather than coupling the supervisor to a vendor-specific message format. Local MCP requests support cancellation and categorized lifecycle errors; ACP responses preserve request correlation and categorize parse, request, parameter, and unsupported-event failures. The shared parser rejects unknown event types, unknown tools, invalid enums, NUL bytes, and oversized fields before they enter supervisor state. Completion checks are evidence-based: the supervisor’s command result supplies status, exit code, duration, bounded output, finish time, truncation state, workspace fingerprint, command digest, and Forge tool version. Persisted session records additionally retain a bounded step journal, checklist, scratchpad, recovery assessment, and verification evidence digest; resume revalidates the fingerprint and never replays a mutation automatically.
GitHub status, login, clone, private repository creation, and push are explicit CLI-supervisor workflows, not worker-authorized protocol capabilities.
