Forge protocol v1 is a line-oriented JSON event stream. One complete JSON object is written per line. The Node.js supervisor and Python worker use the same envelope fields: `protocol`, `id`, `sessionId`, `type`, and `timestamp`.

Standard output is reserved for protocol messages. Standard error is reserved for diagnostics and must never be parsed as an event. Every tool proposal has a named tool, risk classification, JSON arguments, and reason. Every tool result reports approval, success, duration, and either bounded output or a structured error.

The v0.8 contract retains first-class `agent.delegation` events for bounded specialist activity and optional session autonomy profiles. `session.start` may include a bounded workspace fingerprint and a recovery assessment identifying `continue`, `re-plan`, or `manual-intervention` without authorizing replay. Unified-diff application is represented by the reversible-write `workspace.apply_unified_diff` tool and remains supervisor approval-gated; read-only previews can describe a selected file-level change set, while application remains stale-validated, checkpointed, and all-or-rollback. Approval-session decisions carry an ephemeral exact-argument scope and expiry, with bounded path metadata, rather than blanket authorization.

The canonical event schema is [`schema.json`](./schema.json). The TypeScript implementation is in [`src/index.ts`](./src/index.ts). MCP and ACP adapters map their wire-level events to these internal boundaries rather than coupling the supervisor to a vendor-specific message format. Local MCP requests support cancellation and categorized lifecycle errors; ACP responses preserve request correlation and categorize parse, request, parameter, and unsupported-event failures. Completion checks are evidence-based: the supervisor’s command result supplies status, exit code, duration, bounded output, finish time, truncation state, and the workspace fingerprint used to detect stale evidence. Persisted session records additionally retain a bounded step journal, recovery assessment, and verification evidence; resume revalidates the fingerprint and never replays a mutation automatically.
