Forge protocol v1 is a line-oriented JSON event stream. One complete JSON object is written per line. The Node.js supervisor and Python worker use the same envelope fields: `protocol`, `id`, `sessionId`, `type`, and `timestamp`.

Standard output is reserved for protocol messages. Standard error is reserved for diagnostics and must never be parsed as an event. Every tool proposal has a named tool, risk classification, JSON arguments, and reason. Every tool result reports approval, success, duration, and either bounded output or a structured error.

The v0.7 contract retains first-class `agent.delegation` events for bounded specialist activity and optional session autonomy profiles. `session.start` may include a bounded workspace fingerprint. Unified-diff application is represented by the reversible-write `workspace.apply_unified_diff` tool and remains supervisor approval-gated; the read-only preview path reports hashes, actions, and conflicts without writing. Approval-session decisions carry an ephemeral exact-argument scope and expiry rather than a blanket authorization.

The canonical event schema is [`schema.json`](./schema.json). The TypeScript implementation is in [`src/index.ts`](./src/index.ts). MCP and ACP adapters map their wire-level events to these internal boundaries rather than coupling the supervisor to a vendor-specific message format. Completion checks are evidence-based: the supervisor’s command result supplies status, exit code, duration, bounded output, finish time, truncation state, and the workspace fingerprint used to detect stale evidence. Persisted session records additionally retain a bounded step journal and verification evidence; resume revalidates the fingerprint and never replays a mutation automatically.
